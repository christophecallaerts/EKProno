# User Story Map: EKProno

## Goal

Give a group of friends a football prediction pool that runs itself — predictions in before kickoff, points scored automatically, and a live leaderboard that settles who actually knows football.

## Primary User

The **pool organiser** — the person who sets up the pool for a tournament, invites the friend group, decides the scoring rules, and keeps things moving. They want the admin to be effortless so the pool stays about the rivalry, not the bookkeeping. Players are the second audience: they come to predict fast, then watch the leaderboard and talk smack.

## Story Map

### Set up the pool

| #   | Story                                                                                      |
| --- | ------------------------------------------------------------------------------------------ |
| 001 | As an organiser, I create a pool with a name and pick the tournament it follows              |
| 002 | As an organiser, I load the tournament's match schedule, including group stage and knockouts |
| 003 | As an organiser, I choose the scoring rules — how many points a correct outcome is worth, with an extra point on top for an exact score |

### Get everyone in

| #   | Story                                                                           |
| --- | ------------------------------------------------------------------------------- |
| 004 | As an organiser, I invite my friends with a shareable join link                   |
| 005 | As a player, I join the pool through the link and pick my display name            |
| 006 | As a player, I enter my score predictions for the upcoming matches                |
| 007 | As a player, my predictions lock automatically at kickoff so nobody can cheat     |

### Keep it running

| #   | Story                                                                                  |
| --- | --------------------------------------------------------------------------------------- |
| 008 | As an organiser, I enter a match result and everyone's points are recalculated automatically |
| 009 | As a player, I see a per-match breakdown of how my points were earned                   |
| 010 | As an organiser, I see on a dashboard who still hasn't predicted the next round          |

### Drive the rivalry

| #   | Story                                                                                       |
| --- | --------------------------------------------------------------------------------------------- |
| 011 | As a player, I see a live leaderboard with my rank and how I've moved since the last round      |
| 012 | As a player, I compare myself head-to-head against any other player in the pool                 |
| 013 | As a player, I post trash talk in the pool's comment feed                                       |
| 014 | As a player, I read a round recap showing the biggest climber, the best call and the worst miss  |
